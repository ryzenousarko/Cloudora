# ☁️ Cloudora

**Cloudora** is a modern, responsive weather application designed to provide accurate and useful weather information through a clean and user-friendly interface.

Check real-time weather conditions, forecasts, temperature, humidity, wind information, time zones, and more — with automatic location detection for a convenient experience.

## ✨ Features

* 🌤️ Real-time weather information
* 📍 Automatic location detection
* 🌡️ Current temperature and weather conditions
* 💧 Humidity information
* 💨 Wind speed and direction
* 🌧️ Weather forecasts
* 🕐 Time zone information
* 🔍 Search weather by city
* 📱 Responsive design for desktop, tablet, and mobile
* 🎨 Clean and modern user interface
* ⚡ Fast and easy to use

## 🛠️ Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and API integration
* **Weather API** — Real-time weather data

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ryzenousarko/Cloudora.git
```

### 2. Open the project

Open the cloned `Cloudora` folder in **VS Code**.

### 3. Run the application

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## 🔑 API Setup

If the project uses an API key, open `script.js` and add your weather API key where required.

**Important:** Never upload private API keys, passwords, tokens, or other secrets to GitHub.
